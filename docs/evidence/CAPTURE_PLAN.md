# Automated Product Media Plan

## Toolchain

- Playwright launches the Electron application and captures deterministic desktop states.
- Maestro runs fixed mobile flows on iOS Simulator and Android Emulator.
- Mermaid CLI renders architecture, synchronisation and data diagrams.
- Sharp crops, labels and combines captures without changing application content.
- A manifest records file name, source flow, viewport, seed state and README placement.
