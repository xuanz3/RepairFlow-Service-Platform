# v1 Acceptance

RepairFlow v1 is complete only when:

- Android and iOS Simulator complete check-in and evidence capture while offline.
- Windows and macOS run the desktop workshop application.
- Application termination and network interruption do not lose committed work.
- Repeated operations do not duplicate cases, evidence or part-use records.
- Concurrent edits are resolved explicitly and recorded.
- Delivery is blocked until required quality checks and evidence are complete.
- Role and object access rules have automated negative tests.
- Desktop, mobile and service paths have automated verification.
- Release artefacts include checksums, SBOM, release notes and known limitations.
- The final 18 images are generated by the capture pipeline from fixed seed data.
