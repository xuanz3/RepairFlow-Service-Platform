# RepairFlow v0.0.1

This pre-release establishes the product definition and engineering governance baseline.

## Included

- Repair workflow and explicit exclusions
- Desktop and mobile interface direction
- Purposeful motion and accessibility rules
- Modular service and offline synchronisation decisions
- Five-Phase delivery plan
- Meaningful commit and release strategy
- Deterministic 18-image product-media contract
- Issue forms, pull request checks, security policy and repository validation

## Not included

No application runtime is shipped in this release. Runtime foundations begin in Phase 1.
