# RepairFlow v0.3.0-desktop-preview

## Included

- Electron workshop queue and repair case workspace;
- SQLite local workflow persistence through a restricted preload bridge;
- intake, diagnosis, repair action, evidence and quality-review interfaces;
- local evidence file copy and SHA-256 metadata;
- Playwright end-to-end workflow validation;
- Linux, macOS and Windows shell builds.

## Limitations

- the preview is not a signed installer;
- central service synchronisation is not enabled;
- generated local records are used for demonstration;
- durable conflict recovery is introduced in Phase 3.
