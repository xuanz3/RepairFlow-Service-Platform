# RepairFlow v0.2.0-service-core

## Included

- Repair case, device, evidence and audit domain foundations
- PostgreSQL persistence through Entity Framework Core
- ASP.NET Core Identity token endpoints and repair roles
- Liveness and database-readiness health endpoints
- Generated local repair cases
- Docker Compose services for PostgreSQL and Azurite
- Domain, API and cross-platform shell validation

## Limitations

- The initial local schema uses a controlled foundation bootstrap. Versioned upgrade migrations are introduced before persistent user data is supported.
- Client-side SQLite and offline outbox operations are implemented in later phases.
- Preview shells use generated records and are not release packages.
