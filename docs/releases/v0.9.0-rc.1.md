# RepairFlow v0.9.0-rc.1

Release candidate for the v1 packaging and installation matrix. It contains the reviewed application source that will become v1.0.0 after merged-main verification, with generated cross-platform artefacts, checksums and a CycloneDX SBOM.

The release candidate is not the general-availability release. Findings must be corrected through reviewable commits before v1.0.0 is published.
