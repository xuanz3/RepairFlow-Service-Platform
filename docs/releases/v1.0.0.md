# RepairFlow v1.0.0

RepairFlow v1.0.0 delivers the complete offline-first repair workflow across desktop, mobile and service boundaries.

## Included

- Electron workshop workspace for intake, diagnosis, repair actions, evidence, quality review and sync conflicts.
- Expo mobile workflow for check-in, QR/serial lookup, local evidence, diagnosis and offline operations.
- ASP.NET Core service with PostgreSQL, role policies, audit, explicit version conflicts, idempotency and resumable evidence uploads.
- OpenTelemetry reliability signals with Prometheus/Grafana local observability.
- Cross-platform release artefacts for macOS, Windows, Linux, Android and iOS Simulator.
- SHA-256 checksums, CycloneDX SBOM and automated release verification.

Automated emulator/simulator screenshot capture is not part of the v1 release gate; native package generation remains fully verified in CI.
