# RepairFlow v1.0.0

RepairFlow v1.0.0 delivers the first complete offline-first repair workflow across desktop, mobile and service boundaries.

## Included

- Electron workshop workspace for device intake, diagnosis, repair actions, evidence, quality review and synchronisation visibility.
- Expo mobile workflow for check-in, QR/serial lookup, local evidence, diagnosis and offline operations.
- ASP.NET Core service with PostgreSQL, role policies, audit records, explicit version conflicts, idempotency and resumable evidence uploads.
- OpenTelemetry reliability signals with optional local Prometheus and Grafana services.
- Cross-platform release artefacts for macOS, Windows, Linux, Android and iOS Simulator.
- SHA-256 checksums, CycloneDX SBOM, build metadata and automated release verification.
- A curated repository walkthrough showing the desktop and mobile v1 workflows.

## Verification boundary

Desktop end-to-end, accessibility, service, synchronisation and package-generation checks remain blocking. Android APK generation and iOS Simulator package generation are verified in CI, while physical mobile hardware and camera behaviour remain outside the automated release gate.

Product screenshots are maintained as documentation and do not block package creation.
