# Security Policy

## Reporting

Do not open a public issue containing a real credential, private customer record or exploitable third-party target. Testing is limited to the local RepairFlow environment and generated data.

## Repository rules

- Never commit tokens, passwords, signing keys or production connection strings.
- Never use real customer names, device contents, serial numbers or unlock credentials.
- Test uploads must use generated files and allow-listed formats.
- Logs, traces, product media and support bundles must be reviewed for sensitive data.
